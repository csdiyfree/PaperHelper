# 示例论文

`install.sh` 第一次运行时，会把这里的论文复制进论文库的「示例」分类；之后即使你删掉它，重新运行安装脚本也不会再加回来。

这些文件**不适用**仓库的 MIT 许可证，各自的许可如下。

## jiang2023-mistral7b — Mistral 7B

- **原文**：Albert Q. Jiang, Alexandre Sablayrolles, Arthur Mensch, Chris Bamford, Devendra Singh Chaplot, Diego de las Casas, Florian Bressand, Gianna Lengyel, Guillaume Lample, Lucile Saulnier, Lélio Renard Lavaud, Marie-Anne Lachaux, Pierre Stock, Teven Le Scao, Thibaut Lavril, Thomas Wang, Timothée Lacroix, William El Sayed. *Mistral 7B*. arXiv:2310.06825, 2023. <https://arxiv.org/abs/2310.06825>
- **许可**：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。`original.pdf` 是 arXiv 上的原始 PDF（v1），未做修改。
- **改动**：`zh.pdf`（中文译文）、`bilingual.pdf`（中英对照）和 `latex/`（译稿源码）是对原文的翻译和重新排版，由 PaperHelper 的翻译 skill 完成，未经原作者审阅。译文中的「译者注」为翻译时添加。翻译部分同样以 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 发布。
- `text/` 是从上述 PDF 提取的纯文本，供搜索和 AI 使用；`notes.md` 是 PaperHelper 的上手笔记。
