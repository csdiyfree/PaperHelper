## 欢迎使用 PaperHelper

这是随软件附带的示例论文《Mistral 7B》，原文和中文译文都以 CC BY 4.0 授权（署名见仓库里的 `examples/README.md`）。这份笔记就是这篇论文的 `notes.md`，可以随意修改或清空。

### 先试试这些
- **切换版本**：顶部的「中文 / 对照 / 原文」。对照版里每段英文原文在上、中文在下。
- **摘录**：在论文里选中一段文字，点「摘录到笔记」，原文会以引用块的形式加到这里，并标好页码。
- **问 AI**：选中文字点「问 AI」，或者切到右上角的「AI」标签直接提问。第一次用要先点左下角齿轮（`⌘,`），填入 DeepSeek API key。
- **搜索**：`⌘K` 搜索论文，或者把问题直接交给论文库助手。
- **写笔记**：点「编辑」，用 Markdown 写；`- [ ]` 会变成可以勾选的待办。

### 导入你自己的论文
在装好翻译 skill 的 Claude Code 或 Codex 里说「翻译这篇论文 /path/to/paper.pdf」。翻译完成后，论文会自动归类到论文库，并在这里打开。
